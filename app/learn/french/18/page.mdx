# 直説法単純過去形の活用

*第6章 時制より*

## a型（対象：-er動詞）

| 人称 | 語尾 | 例（donner） |
|---|---|---|
| 一人称単数 | -ai | donnai |
| 二人称単数 | -as | donnas |
| 三人称単数 | -a | donna |
| 一人称複数 | -âmes | donnâmes |
| 二人称複数 | -âtes | donnâtes |
| 三人称複数 | -èrent | donnèrent |
