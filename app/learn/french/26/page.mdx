# 感嘆文の形

*第14章 感嘆文と祈願文より*

| 感嘆文の形 | 例文 |
|---|---|
| quel...（＋主語＋述語） | Quel beau paysage! （なんて美しい景色なんだ。） |
| que＋主語＋述語 | Qu'il parle vite! （彼はなんて早口なんだ） |
| comme＋主語＋述語 | Comme elle chante bien! （彼女はなんて歌がうまいんだ。） |
| que de＋名詞 | Que de monde ici! （ここはなんて人が多いんだ。） |

## 祈願文

「Que＋接続法現在形の独立節」の形で作る。

- Que la chance soit avec toi. （幸運があなたと共にありますように。）
