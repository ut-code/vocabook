# 疑問詞一覧

*第4章 否定文と疑問文より*

| 疑問詞 | 意味 | 例文 |
|---|---|---|
| qui | 誰 | Qui est là ? |
| que | 何 | Qu'est-ce que c'est ? |
| quand | いつ | Quand allez-vous au Japon ? |
| où | どこ | Où habites-tu ? |
| combien | いくつ | Combien d'enfants avez-vous ? |
| pourquoi | なぜ | Pourquoi pleures-tu ? |
| comment | どう | Comment allez-vous ? |
| quel | どの | Quelle voiture avez-vous achetée ? |
| lequel | どれ | Laquelle de ces voitures préférez-vous ? |
| quoi | 何 | Avec quoi mangez-vous ce plat ? |

- quelとlequelは性数変化する。
- quoiは前置詞の目的語部分を質問するときに使う。
- 間接疑問文の場合「何が」は「ce qui」に、「何を」は「ce que」になる。
