# 数を使った表現（小数・分数・四則演算）

*第1章 品詞と文型より*

## 小数

小数点はvirgule（記号は「,」）と読み、小数点以下の桁は（特に4桁以上で多い場合は）1桁ずつ区切って読まれることが多い。

- 3,1415：trois virgule un quatre un cinq

## 分数

- 分子や分母が大きい場合：「分子の基数＋sur＋分母の基数」
  - 18/20：dix-huit sur vingt
- 分子や分母が小さい場合：「分子の基数＋分母の序数（分子が2以上の時に複数形変化あり）」
  - 5/8：cinq huitièmes
- 分母が2,3,4の場合は特別な単語がある：demi、tiers、quart
  - 3/4：trois quarts

## 四則演算

| 演算 | 表現 |
|---|---|
| 足し算 | plus |
| 引き算 | moins |
| 掛け算 | fois／multiplié par |
| 割り算 | divisé par |
| イコール | égale／font |
